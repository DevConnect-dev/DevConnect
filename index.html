Fonctionnalités principales
DevConnect 1.0
DevConnect n’est pas juste un chat. C’est une couche sociale pensée pour les développeurs : tu contrôles qui peut t’écrire, qui peut t’appeler, et comment tu te rends disponible.
Système d’amis
Ajoute, accepte, refuse. Les messages privés ne sont possibles qu’entre amis, pour éviter le spam.
Messages privés filtrés
Pas d’accès direct à ta boîte privée. Si vous n’êtes pas amis, pas de MP. Simple.
Appels privés
Un bouton d’appel par ami. Base prête pour brancher du WebRTC (audio/vidéo) côté backend.
Interface moderne
Design sombre, avatars circulaires, cartes, animations légères. Pensé pour les devs, pas pour les pubs.
Communauté & vision
Pour les devs
DevConnect est pensé comme un hub : tu peux y retrouver tes amis devs, tes projets, tes calls, tes échanges. Pas de bruit inutile, pas de feed toxique. Juste des connexions utiles.

À terme : intégration GitHub, statuts de projet, rooms vocales, salons par stack, et plus encore.
Contact & bêta
Bientôt ouvert
Tu peux utiliser cette page comme vitrine de ton projet DevConnect, et brancher plus tard :
  • Formulaire de contact (backend ou service externe)
  • Inscription à la bêta (mail, Discord, etc.)
  • Redirection vers ton GitHub / portfolio
Tech & intégration
Front-first
Ce fichier est 100% front. Tu pourras ensuite :
  • Brancher un backend (Node, Firebase, Supabase…)
  • Remplacer la simulation d’amis par une vraie base de données
  • Brancher WebRTC pour les appels audio/vidéo réels
  • Gérer l’authentification et les profils utilisateurs
